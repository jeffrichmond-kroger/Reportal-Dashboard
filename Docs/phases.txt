Here is the simplified development sequence. The main principle is do not proceed to the next phase until the current phase validates successfully.

Phase	Focus	Main outcome0. Baseline	Git and project safety	Clean baseline/commit and confirmed working PBIP
1. Model cleanup	TMDL/model configuration	Clean fields, sorting, formats, remove unnecessary auto date tables
2. Organization filters	Division → District → Site	Correct disconnected-filter logic resolving to ALL, DIV, DIST, or SITE
3. DAX measures	Retrieve supplied database values	YTD, Weekly, Goal, Color, Arrow, Period/Week measures
4. Data validation	Compare Power BI with Reportal	Period 10 numbers match the legacy dashboard
5. Report shell	Basic page/layout	Filter panel, period area, page structure, help button
6. Score cards	Top KPIs	Total Overall, Care, Service, Share match legacy
7. Main matrix	Detailed scorecard	YTD + Goal + weekly columns and detail rows
8. Period navigation	< Period 10 2026 >	Previous/next period behavior works correctly
9. Visual refinement	Match legacy appearance	Colors, spacing, formatting, labels, alignment
10. Final validation	Full regression	Data, filters, visuals, refresh, performance and Git all validated
